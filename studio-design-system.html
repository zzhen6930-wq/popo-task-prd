WorkHub Studio 后台 · 设计规范 v1.0

参考 Codex 桌面端设计语言（克制、中性、低装饰），结合 B 端组织后台的高信息密度诉求做适配。参考风格，不照搬布局。

2026-08-07青远（张振）适用：Studio 超管后台 + 租户平台

0设计原则（从截图提炼）

  • 中性为底，色彩只做语义：全局灰阶 + 白，彩色只出现在开关、状态、危险操作等极小面积。
  • 边框代替阴影：分层靠 1px 细边框 + 极浅底色，几乎不用投影。
  • 嵌套圆角：外层容器 12px，内部行/输入 8px，标签/图标 6px。
  • 内容居中定宽：主区内容限宽约 760–900px 居中，两侧大留白（后台表格页可放宽到 1100px）。
  • 标题 + 副标题成对：每页顶部一个大标题 + 一行灰色说明，不用面包屑堆叠。
  • 分组用小标题，不用卡片堆卡片：一组设置 = 一个小标题 + 一个带边框的行容器。
  • 操作右置：每一行左侧「名称 + 描述」，右侧一个控件（开关/下拉/按钮）。
与现有 Studio 后台最大差异：去掉靛蓝/紫色主色与渐变、去掉卡片阴影、去掉彩色 pill 泛滥，改为中性黑白 + 行式设置布局。

3间距 / 圆角 / 描边

  • 间距阶：4 / 8 / 12 / 16 / 24 / 32（仅用这 6 档）。
  • 圆角：外层容器 12px；内部行、输入框、按钮、下拉 8px；Pill/小图标底 6px；圆形仅头像。
  • 描边：统一 1px solid #e8e8ea；内部分隔线 #f0f0f2。
  • 阴影：仅两档 —— 常规 none；浮层（弹窗/下拉）0 8px 24px rgba(0,0,0,.10)。禁止卡片默认阴影。
  • 容器内边距：卡片 20–24px；设置行 12px 16px；表格单元格 10px 12px。

4核心组件规范

类型样式用途

行内操作之间用 · 或 12px 间距分隔，不用竖线分隔符。

4.2 设置行（Row）—— 后台核心组件

Codex 全站最主要的信息单元：一组行包在一个 12px 圆角容器里，行间 1px 分隔线，左侧标题 + 描述，右侧控件。

Token 扣除规则

统一从我的额度扣除 ⌄
允许加入群聊
开启后成员可将该 Agent 拉入群聊
  • 行高：单行 48px，带描述 56–60px。
  • 右侧控件仅 4 种：开关 / 下拉 / 次按钮 / 值+箭头。
  • 容器上方可加一个 14px 分组小标题（如「工作空间依赖项」）。

4.3 侧边栏

  • 宽 200px，底色 #f4f4f5，与主区之间 1px 分隔线。
  • 顶部：产品名 + 搜索框（圆角 8px，浅底无边框）。
  • 菜单项：高 30px，圆角 6px，左内边距 10px，图标 14px + 文字 13px（--t2）。
  • 选中态：白底 + 文字 --t1 + 极弱阴影（不用彩色底、不用左侧色条）。
  • 分组：灰色小标题（11.5px，--t3），组间距 16px，不用分割线。
  • 底部固定：当前账号/租户信息。

4.4 页头

主区顶部：大标题（24px）+ 副标题（13px 灰）；右上角放主按钮与全局操作图标。下方为 Tab 或筛选区，不再叠加卡片标题。

5Tab / 筛选 / 表单

5.1 Tab

  • 样式为 胶囊式：未选中无底、文字 --t2；选中 浅灰底 #f0f0f2 + 圆角 8px + 文字 --t1。
  • 不用下划线式 Tab、不用主色下划线。
  • Tab 文字后可跟计数（如 MCP 2），计数为 --t3 常规字重。

5.2 搜索与筛选

  • 搜索框：高 32px，圆角 8px，浅底 #f4f4f5 或白底细边框，左侧放大镜图标，placeholder --t3。
  • 下拉筛选：白底 + 1px 边框 + 圆角 8px + 右侧 ⌄，不用彩色。
  • 筛选区右对齐置于标题行右侧或 Tab 同一行右侧。

5.3 表单

  • 表单整体包在一个 12px 圆角边框容器内，字段之间 16px。
  • Label 13px/500 在上，输入框在下（宽度撑满），圆角 8px、高 34px、白底细边框，focus 时边框转 --t1。
  • 「+ 添加参数」类新增：整行浅灰底虚拟按钮（#f4f4f5，圆角 8px，居中文字 --t2）。
  • 保存按钮右下角，未改动时禁用态。

6表格与状态

  • 表格外包 12px 圆角边框容器；无斑马纹，仅 1px 行分隔线 #f0f0f2。
  • 表头：底 #fafafa、文字 --t2、12.5px/600。
  • 行高 48px，hover 底 #fafafa。
  • 操作列右对齐，使用幽灵按钮。
  • 空态：容器内居中，一个线性图标 + 一句灰字说明 + 一个主按钮。

状态标识（Pill）

圆角 6px、11.5px、无边框、浅底深字，面积尽量小：上架 #eaf5ee/#1a7f4b、下架 #f0f0f2/#5d5d63、异常 #fdf0ef/#c8342b、进行中 #eef4fd/#0b6bcb。也可用 6px 圆点 + 文字替代。

7弹窗与浮层

  • 弹窗宽 440 / 560 / 720 三档；圆角 12px；阴影 0 8px 24px rgba(0,0,0,.10)；遮罩 rgba(0,0,0,.30)。
  • 结构：标题行（16px/700 + 右上 ×）→ 内容区 → 底部操作（左侧辅助操作，右侧主/次按钮）。
  • 复杂配置改用右侧抽屉（宽 520–640），避免高弹窗；简单表单仍用居中弹窗。
  • 下拉/气泡：白底、圆角 8px、同款阴影、内边距 4px，选项高 32px hover 浅灰。
