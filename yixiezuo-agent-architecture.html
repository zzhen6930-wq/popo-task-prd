3四个关键机制（已确认口径）

3.1 实例落地方式：Agent 维度打标，不改 Studio 层级模型

Studio 不新增「实例」层级。从易协作工单平台同步实例信息后，以 instance_id / instance_name 作为 Agent 属性标签 落地。

  • 批量初始化：按实例标签成组生成，一实例一个初始化 PM Agent。
  • 可见性：AgentHub 侧比对「当前用户所属实例」与「Agent 实例标签」，命中才可见。
  • 管理与统计：Studio 列表、用量统计均可按实例标签筛选、分组。
好处
零改造 Studio 核心模型，可复用现有租户/Agent/用量体系；后续其他平台方（非易协作）入驻可套用同一套「外部组织维度打标」范式。

3.2 资产归属：初始化 Agent 与 PM 另建 Agent 均归易协作租户

对象归属租户Studio 可管成本扣除
PM Agent 模版易协作是—
初始化 PM Agent（按实例）易协作是易协作租户账号
PM 引用另建的项目级 Agent易协作是易协作租户账号
个人在 AgentHub 完全自建 AgentAgentHub是（AgentHub 租户下）个人积分
⚠️ 待定
PM 在 AgentHub 另建的项目级 Agent 也计入易协作租户成本 —— 需确认易协作是否接受「PM 自由创建即产生平台方成本」，是否需要配额上限或创建审批。

3.3 模版继承：增量合并（只增不减、不覆盖）

模版变更（新增 Skill A / 新增 MCP B / 改提示词） ↓ 下发到全部「未断开继承」的初始化 PM Agent ↓ Skill / MCP / 知识 → 追加，不删除 PM 已加的，也不移除 PM 停用的 提示词 → PM 未改过 则同步更新；PM 已改过 则保留 PM 版本 ↓ PM 覆盖层永不丢失
  • 只增不减：模版删除某能力时，不从已生成 Agent 中移除（避免误伤 PM 依赖）；如需强制回收另做「批量强制重设」动作，且需二次确认。
  • 断开继承：PM 引用另建的 Agent 为一次性快照，此后与模版无关。
⚠️ 待定
增量合并长期运行后，Agent 配置会「只增不减」持续膨胀。是否需要：① 模版变更前的影响面预览（将影响 N 个 Agent）；② 平台方可见的偏离度视图（哪些 Agent 偏离模版最多）。

3.4 权限与角色

角色主阵地权限范围
易协作平台方Studio管模版、批量初始化、看全部实例 Agent、用量审计、上下架；不介入单个项目的日常配置。

4端到端主链路
① 配模版 易协作平台方在 Studio 配置 PM Agent 模版（提示词 / Skill / MCP / 知识） ↓ ② 拉实例 Studio 同步易协作工单平台的实例清单与成员归属 ↓ ③ 批量初始化 按实例批量生成初始化 PM Agent，自动打 instance_id 标签 + 设定可使用范围 ↓ ④ 定向可见 PM / 成员在 AgentHub「发现智能体」看到本实例的 PM Agent ↓ ⑤ 用与改 直接使用 ｜ 叠加项目 Skill/MCP/知识（PM 覆盖层） ｜ 引用另建项目级 Agent（断开继承） ↓ ⑥ 回流管理 全部 Agent 在 Studio 可查、可审计、可统计用量（按实例 / Agent / 用户维度） ↓ ⑦ 持续下发 模版更新 → 增量合并到未断开继承的初始化 Agent，PM 定制不丢失
5本方案对 Studio 的改造点
模块改造量说明
模版管理中已有超管模版管理，需下沉到租户维度（易协作自己管模版），并支持模版 → 批量实例化。
外部实例同步新增对接易协作工单平台，同步实例与成员；需定义同步频率、实例新增/下线的处理策略。
批量初始化引擎新增按实例成批生成 Agent、打标、设可见范围；支持增量（新实例自动补建）。
继承与增量合并新增模版与实例 Agent 的绑定关系、PM 覆盖层记录、合并规则、断开继承标记。
Agent 列表 / 用量小增加实例标签筛选与分组维度，其余复用现有能力。
AgentHub 侧中发现按实例过滤；初始化 Agent 的编辑权限与覆盖层交互；引用另建入口。
6待你拍板的开放问题
  • 成本与配额：PM 另建的项目级 Agent 记易协作租户账号，是否需要按实例/PM 设创建数量上限或额度上限？
  • 实例变更：实例下线 / 成员调岗时，对应 Agent 是自动下架、转归档还是保留待人工处理？
  • 新实例补建：易协作新增实例后，初始化 Agent 是自动补建还是平台方手动触发？
  • 模版多版本：是否需要多套模版（如按业务线区分），实例与模版是 1:1 还是 N:1？
  • PM 修改边界：提示词是否允许 PM 全量改写，还是仅允许追加段落（保护平台方标准约束）？
  • 共享范围：PM 把项目级 Agent 共享给成员，是否限定在本项目内，能否跨项目？
