WorkHub Studio · Agent 管理能力增强

在一个 Agents 列表中统一管理「自建 Agent（AgentHub / Workhub Studio）」与「外部连接的智能体（Claude Code / Hermes / OpenClaw / Codex 等）」；详情页由单一配置升级为四 Tab，补齐使用范围（分发管控）与用量统计（成本可视）两大管理维度。
📅 2026-08-03 🏷️ v1.0 👤 作者：青远（张振） 🧩 归属：WorkHub Studio · Agents 模块
1背景与目标

平台在同一 Agents 列表 中承载两类智能体：自建 Agent（AgentHub / Workhub Studio）与外部连接的智能体（Claude Code / Hermes / OpenClaw / Codex 等三方接入）。当前二者缺少统一管理入口与管理维度：无来源区分、详情页只有能力配置，管理员看不到「谁能用、成本从谁扣」。

本次目标：一个列表统管两类 Agent，并在详情页补齐使用范围（分发管控）与用量统计（成本可视）两大管理维度。

🔑 定位
「配置」管能力、「使用范围」管分发、「用量统计」管成本，构成 Agent 完整管理视图。具体交互详见原型。
2Agent 列表页

自建与外部连接 Agent 同列表管理，可按名称 / 创建人搜索、按来源筛选；点击行进入详情。列表字段：名称、模型、来源、记忆、状态、创建人 / 时间、更新人 / 时间、操作（编辑 / 删除）。

来源分三类

  • AgentHub、Workhub Studio：自建 Agent。
  • 外部连接的智能体：三方接入，来源列展示具体三方名（Claude Code / Hermes / OpenClaw / Codex 等）。
3外部连接的智能体

三方智能体的角色、技能、工具由三方侧维护，平台可见 / 可管理的信息有限，故做差异化：

  • 列表：模型、记忆显 -；来源显具体三方名。
  • 详情：隐藏「配置 / 记忆」Tab；使用范围与自建一致；用量统计仅保留概览，不含扣除规则 / 额度 / 用户明细 / 趋势（扣费逻辑对三方不适用）。
4详情页布局（Tab 化）

详情页由单一配置改为 4 个 Tab：配置、记忆（已有逻辑，仅归位）+ 使用范围、用量统计（本次新增）。外部连接智能体隐藏「配置 / 记忆」。

5使用范围（新增）

后台管理视角，管理员在 Agent 维度管理「谁能用」与「在各群怎么回复」。

5.1 可使用范围

  • 仅自己：仅拥有者可搜索、私聊、使用；加入群聊后群成员可在群内对话。
  • 指定成员或部门：范围内成员可搜索、私聊、使用并加入群聊。范围通过「选择人员」选择部门或人员（交互详见原型）。

5.2 已加入的群聊

列出该 Agent 所在全部群聊，管理员可按群设置回复方式：智能回复（自主判断是否应答）/ 仅 @ 时回复。会话上下文与其他私聊、群聊隔离（只读）。

边界
本 Tab 只做已入群的查看与回复方式治理，不提供拉 Agent 进群入口；进新群需前往目标群设置。
6用量统计（新增）

在 Agent 维度呈现该 Agent 的 Token 消耗、会话 / 任务量、影响面与近期趋势，并管理 Token 扣除规则。用于成本可视与配额治理。外部连接的智能体仅展示 6.1 用量概览，隐藏 6.2~6.5。

6.1 用量概览

顶部可选时间范围（默认近 7 天 / 月度 / 自定义），指标随范围联动。

五项指标：总用量（Token）、总会话数、总任务数、用户数（去重影响面）、加入群组数，均按所选时间范围统计。

6.2 Token 扣除规则

规则决定该 Agent 产生的 Token 从谁的额度扣，二选一，可查看可修改（切换即时生效、不追溯历史）：

  • 统一从我的额度扣除：无论谁用，都从 Agent 创建时配置的账号额度扣。
  • 从提问人的额度扣除：谁发起对话就扣谁的额度。

6.3 额度（AIGW Token 额度）

展示拥有者账号的已使用 / 剩余 / 本月总额度（进度条）。额度固定展示拥有者，不随扣除规则变化。

6.4 按用户用量明细

两种扣除规则下都按用户拆分展示各自 Token 消耗、会话 / 任务数、占比，便于识别高消耗用户。「扣除归属」列显示实际扣谁的额度（直接显示人名）：

  • 统一从我的额度扣除 → 归属拥有者。
  • 从提问人的额度扣除 → 归属各用户本人。

6.5 趋势分析

折线图展示近期 Token 消耗 / 任务数量 趋势，两维度可切换。

7范围与非目标

✅ 本期做

  • Agent 列表页统一管理两类 Agent，补齐来源、操作列，支持搜索与来源筛选。
  • Agent 详情页 4 Tab（配置 / 记忆 / 使用范围 / 用量统计）。
  • 使用范围：可使用范围（仅自己 / 指定成员或部门）+ 已加入群聊回复方式。
  • 用量统计：概览、扣除规则（可改）、拥有者额度、按用户明细、趋势。
  • 外部连接智能体差异化：列表模型 / 记忆显 -；详情隐藏配置 / 记忆，用量仅概览。

🚫 本期不做

  • 不改动「配置」「记忆」既有逻辑，仅做布局归位。
  • 「已加入的群聊」不提供拉 Agent 进群入口。
  • 扣除规则切换不追溯历史消耗。
  • 不新增账号来源（组织 / 个人）的区分维度。
