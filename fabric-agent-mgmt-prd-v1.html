WorkHub Studio · Agent 管理能力增强

Agent 详情页由「单一配置」升级为「配置 / 记忆 / 使用范围 / 用量统计」四 Tab；新增使用范围与用量统计两大管理维度，补齐后台侧的分发管控与成本可视。
📅 2026-08-03 🏷️ v1.0 👤 作者：青远（张振） 🧩 归属：WorkHub Studio · Agents 模块
1背景与目标

当前 Agent 详情页仅承载能力配置（基础信息、内置工具、Prompt / Skill / MCP 绑定），缺少管理维度：管理员无法在 Agent 视角查看「谁能用、进了哪些群、如何回复」，也无法查看「用了多少 Token、多少会话 / 任务、成本从谁扣」。本次在 Agent 详情页补齐两块管理能力——使用范围 与 用量统计。

目标

  • Agent 详情页顶部改为 4 个 Tab：配置、记忆、使用范围、用量统计。
  • 使用范围：在 Agent 维度管理可使用人 / 部门、查看已加入群组及各群回复方式。
  • 用量统计：在 Agent 维度呈现用量概览、Token 扣除规则（可改）、额度与趋势。
🔑 一句话定位
「配置」管能力，「使用范围」管分发，「用量统计」管成本。三者合起来构成 Agent 在 Studio 后台的完整生命周期管理视图。
2页面布局调整（Tab 化）

进入 Agent 详情页后，顶部由原横排字段区改为 Tab 导航，共 4 个 Tab，默认停留「配置」。

配置记忆使用范围用量统计
Tab状态说明

3使用范围（新增）

管理员在 Agent 维度查看并管理谁能发现、私聊、使用这个 Agent，以及该 Agent 已加入哪些群、在各群的回复方式。C 端使用范围页是「用户自助」视角，本 Tab 是后台管理视角——面向管理员，强调集中查看与治理，而非本人自服务。

3.1 可使用范围

选项含义
仅自己仅 Agent 拥有者可搜索、私聊、在 WorkHub 中使用；加入群聊后群成员可在群内与其对话。
指定成员或部门范围内成员可搜索、私聊、使用并将该 Agent 加入群聊。管理员可选择 / 增删成员与部门（支持部门树多选）。
后台视角差异
C 端是拥有者本人调整自己 Agent 的范围；后台是管理员对本组织下任一 Agent 进行范围查看与调整，用于统一治理（如收敛越界分发、批量授予部门）。

3.2 已加入的群聊

列出该 Agent 当前所在的全部群聊，管理员可查看并按群设置回复方式。

字段说明
群名称Agent 所在群聊名称。
上下文隔离提示「会话上下文与其他私聊、群聊隔离」（已有能力，只读展示）。
回复方式每群独立设置：智能回复（Agent 自主判断是否应答）/ 仅 @ 时回复（被 @ 才应答）。可在此直接切换。
  • 查看：Agent 进了哪些群、每群的回复策略一目了然。
  • 管理：管理员可直接修改各群回复方式；将 Agent 添加进新群仍需前往对应群操作（本 Tab 仅做查看与回复方式治理，不承担「拉 Agent 进群」入口）。
边界
「已加入的群聊」不提供在此新增群聊的入口；添加请前往目标群设置。本 Tab 聚焦已入群的集中查看与回复策略调整。
4用量统计（新增）

在 Agent 维度呈现该 Agent 的 Token 消耗、会话 / 任务量、影响面与近期趋势，并管理 Token 扣除规则。用于成本可视与配额治理。

4.1 用量概览

顶部支持时间范围选择（如本月 / 近 7 天 / 自定义），下列指标随所选范围联动统计。

4.2 Token 扣除规则

展示当前规则并支持修改。规则决定该 Agent 产生的 Token 从谁的额度扣。二选一，不区分账号来源（组织申请账号或员工个人账号，配置时选定的即为「我的额度」对应账号）。

规则扣除逻辑额度卡展示主体
统一从我的额度扣除所有人使用该 Agent 产生的 Token，统一从 Agent 创建时配置的账号额度扣除（无论谁用）。展示该配置账号 / 拥有者的额度。
从提问人的额度扣除每次对话产生的 Token，从发起本次对话的用户额度扣除（谁用扣谁）。展示提问人 / 使用者维度的额度归属。
规则可查看可修改
后台展示当前规则并提供「修改」入口，管理员可在两种规则间切换。切换即时生效于后续对话，不追溯历史消耗。

4.3 额度（AIGW Token 额度）

展示已使用 / 剩余额度 / 本月总额度三项，并以进度条呈现使用占比与同步时间。额度主体随扣除规则自适应（见 4.2）：

  • 规则为「统一从我的额度扣除」→ 展示 Agent 拥有者 / 所配账号 的本月额度。
  • 规则为「从提问人的额度扣除」→ 展示使用者维度的额度归属口径。
字段说明
已使用本月已消耗的 Token。
剩余额度本月剩余可用 Token。
本月总额度本月账号可用于公司 AI 工具的共享总额度。

4.4 按用户用量明细

无论采用哪种扣除规则，都需按用户拆分展示每个使用者的消耗，让「谁用了多少、扣了多少」清晰可见。以列表呈现，支持按 Token 消耗排序、按时间范围联动。

字段说明
用户使用该 Agent 的成员（头像 / 姓名 / 部门）。
Token 消耗该用户在时间范围内消耗的 Token 数。
会话数 / 任务数该用户产生的会话与任务量。
占比该用户消耗占该 Agent 总消耗的百分比。
扣除归属该用户消耗实际从谁的额度扣——随扣除规则不同而不同（见下）。
扣除规则明细展示重点
统一从我的额度扣除虽统一从同一账号扣，但仍按用户拆分展示各自消耗量与占比，让拥有者清楚「这笔统一账单里，每个人分别用了多少」，便于识别高消耗用户。扣除归属列统一显示「拥有者账号」。
从提问人的额度扣除本就谁用扣谁，更需逐用户列出各自消耗与扣除额度；扣除归属列显示该用户本人，与其个人额度对应。
🔑 核心诉求
两种规则下都按用户明细化：区别只在「扣除归属」——统一扣时归属拥有者账号、按提问人扣时归属各用户本人；消耗量拆分展示在两种规则下都保留。

4.5 趋势分析

以柱状 / 折线图呈现近期趋势，支持在两个维度间切换（默认近 7 天）：

  • Token 消耗趋势：横轴日期，纵轴 Token 数。
  • 任务数量趋势：横轴日期，纵轴任务数量。
5范围与非目标

✅ 本期做

  • Agent 详情页 4 Tab 布局（配置 / 记忆 / 使用范围 / 用量统计）。
  • 使用范围：可使用范围（仅自己 / 指定成员或部门）+ 已加入群聊查看与回复方式管理。
  • 用量统计：概览指标（时间范围可选）、Token 扣除规则（可改）、额度卡（自适应）、按用户用量明细、趋势分析。

🚫 本期不做

  • 不改动「配置」「记忆」既有逻辑，仅做布局归位。
  • 「已加入的群聊」不提供拉 Agent 进群入口。
  • 扣除规则切换不追溯历史消耗。
  • 不新增账号来源（组织 / 个人）的区分维度。
