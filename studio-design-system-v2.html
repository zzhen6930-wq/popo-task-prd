0设计升级的 6 条主张

这 6 条决定「像不像 Codex」，比配色重要得多。后续所有页面必须满足。

#主张含义与判定标准
1去容器化删掉"卡片包卡片"。一屏最多 1 层容器边框。模块标题裸露在容器外，不再包一层白卡。判定：任意元素外层边框嵌套 ≤1。
2行式信息单元凡"一个对象 + 一个设置"的场景，一律用设置行，不用表格、不用卡片、不用表单。判定：列数 ≤3 且其中一列是操作 → 必须用设置行。
3内容限宽居中配置/详情类页面主区限宽 860px 居中；纯数据表格页限宽 1180px。不做通栏铺满。
4单色线性图标全站禁用 emoji 与彩色图标，统一 16px stroke-1.5 线性 SVG，颜色继承文字色。
5抽屉优先任何超过 3 个字段或需要浏览列表的操作，用右侧抽屉，不用居中弹窗。弹窗只留确认类。
6信息减法每行重复的静态说明上提到标题下说一次；卡片内信息 ≤3 条；表格列 ≤6 列，超出收进详情或 ···。
反面示例（当前 Studio）：「已加入的群聊」用 3 列表格，第 2 列每行都是同一句"会话上下文与其他私聊、群聊隔离"；外层还包了一层白卡。→ 违反第 1、2、6 条。

3核心组件 A：容器与信息单元

3.1 Section（模块）—— 替代"白卡片"

模块 = 裸标题 + 可选说明 + 一个容器。标题不在容器内，容器只包内容。

✗ 旧做法
白卡片 → 卡内标题 → 卡内又一个带边框表格 → 每行重复同一句说明
✓ 新做法
裸标题 + 计数 → 说明只说一次 → 一个圆角容器装设置行

3.2 SettingRow（设置行）—— 全站最核心组件

结构：[图标/首字母] 标题 + 描述 ......... 控件。多行包在一个 12px 圆角容器内，行间 1px 分隔线。

属性规则
高度带描述 56px；单行 48px；带头像/图标同高
内边距0 16px
左侧标题 13.5/500 + 描述 12.5/t2（描述可省略）
右侧控件仅 6 种：开关 / 下拉 / 次按钮 / 值+箭头（可点进抽屉）/ 只读值 / ··· 菜单
可点整行控件为「值+箭头」时整行可点，hover 底 #fafafa
禁用整行 opacity .5，控件不可点
使用判定：当一组数据满足「每条 = 一个对象 + 一个可改设置」，必须用 SettingRow，禁止用表格。例：已加入群聊、Skill 绑定、MCP 绑定、租户分配、扣费规则。

3.3 Table（表格）—— 仅用于多维数据

  • 使用条件：列数 ≥4 且每列信息不同、需要排序/分页。否则改用 SettingRow。
  • 外层 12px 圆角边框，无阴影、无斑马纹；行高 52px；行分隔 1px #f0f0f2；hover 底 #fafafa。
  • 表头：底 #fafafa、12.5px/600/t2、无粗边框。
  • 主列 = 首字母方块 + 名称（13.5/500）+ 副信息（12.5/t2）两行结构。
  • 操作列：收敛为一个 ··· 图标按钮，点开下拉菜单（编辑 / 上下架 / 删除）。不再平铺多个图标按钮。
  • 列上限 6 列；数字列右对齐 + tabular-nums；时间列 12.5px/t2。
  • 行点击 = 进入详情；操作按钮需 stopPropagation。

3.4 StatCard（指标卡）

  • 内容只放 3 样：标题（+ ⓘ）、大数字、环比。不再在卡内堆场景明细（下沉到趋势图）。
  • 容器：12px 圆角、1px 边框、无阴影、内边距 16px 18px。
  • 大数字 26px/700/tabular-nums；环比与数字基线对齐，格式 ▲ 1.2k · 12.4%，涨红跌绿。
  • 栅格：4 列等宽，间距 12px。

3.5 EmptyState（空态）

容器内居中：20px 线性图标（t3）→ 8px → 一句说明（13px/t2）→ 12px → 一个主按钮。容器保持 12px 圆角边框，底 #fafafa，高度 ≥ 200px。不用插画。

4.2 输入 / 搜索 / 下拉

  • 搜索框（Codex 特征）：静止态 浅灰底 #f4f4f5 + 无边框，h32、r8、左侧 16px 图标、placeholder t3；focus 转白底 + 1px #0d0d0d 边框，无光晕。
  • 输入框：白底 + 1px #e8e8ea，h34、r8；focus 边框转 #0d0d0d，禁用彩色 focus ring。
  • Textarea：min-height 88px，resize vertical，其余同输入框。
  • 下拉：触发器同 Secondary 按钮样式 + 右侧 12px ⌄；菜单白底、r8、阴影档 3、内边距 4px、选项 h32/r6，hover #f4f4f5，选中 #f0f0f2 + 右侧对勾（黑）。
  • 新增行按钮（"+ 添加参数"）：整行浅灰底 #f4f4f5、r8、h34、居中文字 12.5/t2；hover #ebebed。

4.3 选择控件

  • 开关 Switch：38×22，r11；关 #d8d8dc，开 #0b6bcb（全站唯一蓝）；滑块白色 18px。
  • 复选框：18×18，r4，1.5px #c4c4ca；选中 黑底黑边 + 白勾。
  • 单选：18×18 圆，1.5px #c4c4ca；选中黑边 + 8px 黑心点。
  • 选择卡（RadioCard）：1px 边框 + r8；选中 边框转 #0d0d0d + 底 #fafafa，不用彩色底。

4.4 Tab / 分段器 / 筛选

  • Tab = 胶囊式：外层 #f0f0f2 底 + 3px padding + r8；项 h26/r6/13px/t2；选中 白底 + t1 + 阴影档 2。禁用下划线式 Tab。
  • Tab 后可跟计数（11.5/t3/常规字重）。
  • 分段器（日/周/月）样式同 Tab，尺寸更小（h24）。
  • 筛选区：右对齐，置于页头右侧或 Tab 同行右端；多个筛选器间距 8px。

4.5 状态标识

形态样式用途
Pillr6、11.5px/500、padding 3px 8px、浅底深字、无边框状态：上架 #eaf5ee/#1a7f4b；下架 #f0f0f2/#5d5d63；异常 #fdf0ef/#c8342b；进行中 #eef4fd/#0b6bcb

约束：同一行内 Pill ≤2 个。分类信息（来源、模型）一律用中性标签，不给颜色。

5浮层体系：抽屉 / 弹窗 / 菜单 / 反馈

5.1 选型规则（强制）

场景用什么说明
字段 ≥3 的创建/编辑右侧抽屉MCP 编辑、模版配置、Agent 编辑
需要浏览/搜索列表后选择右侧抽屉选择人员、绑定 Skill、绑定 MCP、分配租户
字段 ≤2 的快速创建居中弹窗 440新建模版（名称 + 描述）
二次确认 / 危险操作居中弹窗 440删除确认、下架确认
查看只读详情右侧抽屉用量下钻、日志详情
轻量选择下拉菜单回复方式、状态筛选
原则：抽屉优先。抽屉不打断上下文（列表仍可见），且能承载长表单不出现内部滚动条嵌套。

5.2 抽屉（Drawer）

  • 宽度三档：480（简单表单）/ 600（默认）/ 760（左右分栏，如选择人员）。
  • 右侧贴边、满高、左上左下圆角 12px，阴影档 3；遮罩 rgba(0,0,0,.30)。
  • 结构：Header（标题 16/700 + 副标题 + 右上 ×） → Body（可滚动，padding 20px 24px） → Footer（固定底部，1px 上边线，右对齐 取消 + 主按钮）。
  • 动效：transform:translateX(100%)→0，.22s cubic-bezier(.2,.9,.3,1)。
  • 关闭：× / Esc / 点遮罩；有未保存改动时点遮罩不关闭，弹二次确认。
  • 主按钮默认禁用，检测到字段变更后启用。

5.3 弹窗（Modal）

  • 宽 440（确认/快速表单）或 560（略复杂）；r12；阴影档 3；居中；遮罩同上。
  • 结构：标题 16/700 → 说明 12.5/t2 → 内容 → 底部右对齐按钮。
  • 危险确认：标题直述后果，主按钮为 Danger 实心（底 #c8342b、白字），且需输入名称确认时才启用。

5.4 下拉菜单 / Tooltip

  • 菜单：白底 r8、padding 4px、阴影档 3、min-width 140；项 h32/r6/13px；分组间加 1px #f0f0f2 分隔；危险项文字 #c8342b。
  • Tooltip：黑底 #0d0d0d、白字 12px、r8、padding 8px 10px、max-width 260、延迟 300ms 出现，带 5px 小三角。用于指标口径说明。

5.5 反馈

  • Toast：底部居中、黑底白字、r8、13px、阴影档 3、2.4s 自动消失。仅用于成功/失败短提示。
  • 行内错误：输入框边框转 #c8342b + 下方 11.5px 红字，不用弹窗报错。
  • 加载：骨架屏（#f4f4f5 圆角块 + 微弱呼吸），不用转圈 spinner 占满屏。
  • 保存：设置行类改动即时保存 + Toast；表单类改动需显式点保存。

8数据浏览：筛选 / 分页 / 空态

补充规范。凡列表页数据量可能 >20 条或需多条件收敛，必须按本章执行。

8.1 筛选栏 FilterBar

[ 搜索关键词 ]  [ 类型 ▾ ]  [ 状态 ▾ ]  [ 时间范围 ▾ ]      [ 清空 ]
  • 单行横排，不换行不折叠；超过 5 个条件时把低频项收进「更多筛选 ▾」下拉。
  • 控件统一 32px 高，间距 8px；不加 label 文字，用 placeholder 表达（「全部状态」）。
  • 有任一条件生效时，最右出现 清空 ghost 按钮；无生效条件时隐藏。
  • 筛选即时生效，无「查询」按钮。结果数展示在表格标题右侧计数 pill。

8.2 四种选择控件的选型

控件用于规则

8.3 分页 Pagination

  • 位置：表格容器内底部，与最后一行同宽，上边框 1px。高 48px。
  • 左侧「共 128 条」灰字；右侧「每页 20 条 ▾」+ 页码。
  • 总页数 ≤7 全展开；>7 用 1 2 3 … 12 省略式。当前页黑底白字 28×28 圆角 6。
  • 事件流 / 日志等无限追加场景改用 上一页 / 下一页 双按钮 + 「第 3 页」文字，不算总数。

8.4 空状态 EmptyState

场景文案动作
从未创建「还没有 XX」+ 一句价值说明Primary 按钮「创建 XX」

  • 结构：线性 SVG 图标 40px（--t3 色）→ 标题 14px/600 → 说明 13px/--t2 → 按钮，整体垂直居中，容器最小高 240px。
  • 禁止使用插画、彩色空态图。

8.5 加载态

  • 首屏 / 换页：骨架屏——用 --line2 灰条按真实行高铺，1.2s opacity .6↔1 呼吸，不用 shimmer 扫光。
  • 局部（保存中）：按钮内文字换成「保存中…」并 disabled，不加 spinner。
  • 抽屉内异步加载：正文区骨架，Footer 按钮保持 disabled。

9内容展示：代码 / Markdown / 树 / 展开行

9.1 等宽内容块 CodeBlock

背景 #fafafa ｜ 边框 1px --line ｜ 圆角 8 ｜ padding 14/16
字体 Menlo 12px / 行高 1.75 ｜ 色 #3f3f46 ｜ white-space: pre-wrap
右上角常驻「复制」ghost 图标按钮（hover 显形，点击后 1.5s 内变 ✓）
  • 三种用途统一同一外观：JSON 原始数据、运行日志 / 输出、请求示例代码。
  • 超过 16 行自动折叠，底部渐隐 + 「展开全部（共 82 行）」文字按钮。
  • 语法高亮只用 3 色：注释 --t3、关键字 #0d0d0d 600、字符串 --ok。不用彩虹配色。
  • 多语言示例（curl/python/node）用顶部段控 Tab，紧贴代码块上沿，无独立容器。

9.2 Markdown 渲染块

  • 用于展示模型输出、知识片段、Agent 回复。不加外框，直接排在容器内。
  • 限定支持：h4（14px/600）、p、ul/ol、table（同全站表格样式）、a（--acc 无下划线 hover 加）、行内 code、引用块（左 3px --line 竖线）。
  • 渲染 / 原始两态用右上角段控切换，默认渲染态。

9.3 树形导航 Tree

    2026-08-06.md

  • 目录节点右侧灰色计数（纯数字，不加背景）；叶子节点 hover --hover，选中 --side 底 + 文字加粗。
  • 树最大宽 240px，作为左右分栏的左栏使用；不做多层浮动展开。
  • 节点类型区分只用图标（文件夹 / 文档），禁止彩色标签。

9.4 表格内联展开行 ExpandableRow

规则说明

  • 顶部左侧显示文件路径 chip（如 AGENTS.md），右侧「恢复默认」ghost。
  • 底部右下角显示字符数 1,204 / 8,000，超限变 --err。
  • 放在抽屉内编辑，不在设置行里直接放大 textarea。

  • 默认掩码 sk-••••••••••••4f2a（保留后 4 位），右侧「显示」眼睛图标 + 「复制」图标。

10时间线与运行记录

10.1 左右分栏 MasterDetail

┌── 左 380px ─────┬── 右 自适应 ────┐

  • 用于：会话事件流、执行历史、记忆文件浏览。内嵌布局，不是浮层抽屉。
  • 左栏定宽 380（树形浏览取 240），右栏最小 480；中间 1px --line2 分隔。

10.2 事件流 EventStream

  • 按轮次 run 分组：组头一行灰字「第 3 轮 · 14:22:05 · 2.4s · 1,820 tokens」，sticky 吸顶。
  • 事件行：角色标签 + 摘要 + 右侧指标，行高 40，hover 显示「定位 ⌖」。
  • 长时间无活动插入空闲分隔带：一行居中灰字「空闲 2 小时 14 分」，上下 1px 虚线。
  • 指标（耗时 / token）用等宽字体右对齐，保证多行数字纵向对齐。

10.3 角色标签色彩系统

这是全站唯一允许成组用色的地方（因为需要快速区分 8+ 种类型）。用法：11px 文字 + 对应色，不加背景块，仅在必要时用 8% 透明底。

10.4 运行状态语义

状态Dot 色文案规则

10.5 运行详情

  • 顺序固定：状态与耗时 → 触发来源 → 输出内容 → 产出物 → 错误。
  • 输出用 9.1 代码块；产出物为设置行列表（图标 + 文件名 + 大小 + 下载）。
  • 失败时错误块置顶：左 3px --err 竖线 + 淡红底，等宽错误码 + 中文说明 + 「重新运行」ghost。

10.6 锚点联动

  • 右栏详情内点「定位 ⌖」→ 左栏 scrollIntoView({block:"center"}) + 目标行黄底高亮 1.2s 渐隐。
  • 聚焦单轮时左栏顶部出现 sticky 横幅「仅显示第 3 轮 · 返回全部」。

10.7 告警横幅 Banner

  • 位置：PageHeader 下方、内容区上方，与内容同宽，圆角 8，左 3px 语义色竖线 + 极淡底。
  • 结构：图标 + 一句话 + 右侧行动文字按钮 + 关闭 ✕。每页最多 1 条，多条合并为「3 项配置异常，查看详情」。

  • 结构固定三段：频率下拉 → 参数区（随频率切换） → 执行时间，横排在同一行，控件间距 8px。

13.2 验收清单（逐页自查）

  1. 页面内是否存在卡片套卡片？→ 必须为 0。
  2. 是否有 ≤3 列且含操作列的表格？→ 必须改为 SettingRow。
  3. 是否有每行重复的静态文案？→ 上提到说明行。
  4. 是否还有 emoji 或彩色图标？→ 必须换单色线性图标 / 首字母方块。
  5. 主区是否通栏铺满？→ 必须限宽 860 / 1180 居中。
  6. Primary 按钮是否 >1 个？→ 必须 ≤1。
  7. 是否存在彩色卡片阴影或渐变？→ 必须去除。
  8. 复杂编辑是否还在居中弹窗？→ 必须改抽屉。
  9. 彩色像素占比是否 <2%？
  10. 指标卡内信息是否 ≤3 条？
  11. 列表是否可能 >20 条？→ 必须有分页与空状态两种态。
  12. 加载是否用了 spinner？→ 必须换骨架屏。
  13. 是否有彩色角色 / 类型标签？→ 仅事件流与日志允许（第 10.3 节色板），其余场景一律中性。
  14. 周期 / 规则类配置是否有自然语言回显？→ 必须有。
  15. 代码 / JSON / 日志展示是否统一为第 9.1 节代码块？→ 必须统一，且带复制。
  16. 树 / 展开行嵌套是否 ≤2 层？条件构建器是否 ≤2 层？
  17. 密钥类字段是否明文展示？→ 必须掩码 + 手动显示。
