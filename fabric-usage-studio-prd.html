WorkHub Studio 超管后台 · 用量统计

在超管后台新增「用量统计」菜单，从平台 / 租户视角查看用量。与租户平台「Agent 管理 - 用量」页最大区别：统计维度不是单个 Agent，而是某租户下全部 Agent 的汇总。
📅 2026-08-05 🏷️ v1.0 👤 作者：青远（张振） 🧩 归属：Workhub Studio Admin
1背景与目标

租户平台的用量页只能看单个 Agent 的消耗，超管缺少平台侧的整体视角：某租户一共用了多少 Token、集中在哪些场景、趋势如何、谁是高消耗用户。

本期在超管后台新增「用量统计」菜单（位置：MCP 管理下方），提供按租户汇总的用量视图，用于平台侧的成本观测与资源分配决策。

🔑 一句话定位
同一套用量指标与口径，换一个统计主体：从「一个 Agent」升到「一个租户 / 全平台的所有 Agent」。具体交互详见原型。
2与租户平台「Agent 管理 - 用量」的区别

两者复用同一套指标口径与图表逻辑，差异集中在统计主体、筛选维度、模块取舍三点：

对比项租户平台 · Agent 详情-用量超管后台 · 用量统计
统计主体单个 Agent 的用量某租户下全部 Agent 的汇总（默认全部租户 = 全平台汇总）
使用者Agent 拥有者 / 租户管理员平台超管
页面入口Agent 详情页「用量」Tab超管后台左侧菜单「用量统计」（MCP 管理下方）
页面顶部展示 Agent 信息（名称 / 来源 / 拥有者）+ Tab不展示任何 Agent 信息，「用量概览」即页面第一行
筛选维度仅时间范围时间范围 + 租户筛选（默认全部租户），切换后全页联动
Token 扣除规则有，可查看与修改（决定扣谁额度）无此模块（扣费规则属于单 Agent 配置，超管仅观测不配置）
用户用量明细含「扣除归属」列无「扣除归属」列，其余一致
指标口径完全一致：总 Token 用量 / 总会话数 / 总消息数 / 总用户数，差别只在统计范围（单 Agent vs 租户全部 Agent）
⚠️ 口径注意
总用户数为去重值：同一用户在该租户下使用了多个 Agent，只计 1 人，不做各 Agent 用户数的简单相加。会话 / 消息 / Token 则为各 Agent 求和。
3页面构成

3.1 用量概览

页面第一行，右侧为租户筛选与时间范围（近 7 天 / 本月 / 自定义，默认近 7 天）。四项指标各展示总量、按应用场景拆解（Workhub / POPO-单聊 / POPO-群聊 / SDK 及占比）与环比（绝对值 + 百分比，对比上一等长周期）。

指标口径（统计范围 = 所选租户下全部 Agent）
总 Token 用量该范围内所有 Agent 使用过程中消耗的 Token 总量。
总会话数用户与该范围内 Agent 发起的会话总数（非消息数）。
总消息数该范围内 Agent 成功回复的消息总数，每回复一条计 1。
总用户数与该范围内 Agent 对话过的去重用户总数。

3.2 变化趋势

四项指标各一张趋势图，每张同时展示总量 + 4 个应用场景共 5 条线，可单独勾选显隐；支持 日 / 周 / 月 粒度切换，横轴随时间范围与租户筛选联动。

3.3 用户用量明细

按用户展示 Token 消耗、会话数、消息数、涉及的应用场景标签与占比；默认按 Token 消耗降序，分页每页最多 10 条，用于定位租户内高消耗用户。

4范围与非目标

✅ 本期做

  • 超管后台新增「用量统计」菜单（MCP 管理下方）。
  • 租户筛选（默认全部租户）+ 时间范围，全页联动。
  • 用量概览（4 指标 + 场景拆解 + 环比）、变化趋势、用户用量明细。

🚫 本期不做

  • 不提供 Token 扣除规则的查看与修改。
  • 不下钻到单个 Agent 维度的用量列表。
  • 不提供额度调整、限额、告警等治理动作。
  • 不提供数据导出。
