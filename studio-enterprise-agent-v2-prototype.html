审批规则说明

企业 Agent 上架后变更规则

企业 Agent 首次上架需要审核；上架后修改关键字段需重新审核。

展示规则：仅「已上架」状态的 Agent 在企业伙伴中展示。已上架 Agent 重新提交审核后立即停止展示；审核通过后恢复展示，审核未通过时保持不展示。
变更内容是否重新审核生效方式审核重点
名称、头像、描述需要提交后进入审核中，停止展示身份一致、表达准确、无误导或违规内容
分类标签、展示标签、部门标签需要提交后进入审核中，停止展示标签与实际能力匹配，企业提供方真实有效
使用范围需要提交后进入审核中，停止展示无过度授权，敏感能力仅向必要用户开放
其余配置不需要保存后直接生效由租户管理员持续治理
状态流转
未上架→ 提交审核中→ 通过已上架
审核中→ 拒绝审核未通过→ 修改并重提审核中
已上架→ 关键字段变更并提交审核中（停止展示）→ 通过已上架
审核中（停止展示）→ 拒绝审核未通过（不展示）→ 修改并重提审核中（停止展示）

产品需求文档

本期产品 PRD

范围仅包含企业与个人 Agent、标签、模型配置及审批流四类产品逻辑。

01创建企业 Agent 相关逻辑
Agent 归属
  • Studio 后台通过“新建 Agent”或“连接自建云端 Agent”创建的 Agent，均为企业 Agent。
  • 易协作、QA Agent 等接口创建的 Agent，属于个人 Agent。
企业 Agent 专属
  • 详情 配置 → POPO → 群组设置：已加入群组可配置关键字、智能回复提示词、避免打扰；新增“群组权限”，控制是否允许拉智能体进入群组，默认关闭。
  • 详情“使用”Tab：可使用范围增加“全员”，代表对全员可见；新增使用场景运营位，可配置标题和 Query，引导用户使用。
  • 以上能力对个人 Agent 不生效。
个人 Agent 不变创建必填字段不变；开发者、分类标签、部门标签非必填。详情“使用”Tab 维持原可使用范围和可编辑范围。
个人 Agent 变化
  • 配置开发者后，工作伙伴消费侧展示开发者，不再展示创建人。
  • 详情 配置 → 基础信息 与 配置 → POPO 使用和企业 Agent 一致的配置模板；个人 Agent 无“群组设置”，默认允许拉入群聊，无需配置群组权限。
02标签相关逻辑
网易 POPO 租户可新增、编辑分类标签和部门标签；两类标签作为平台共享字典。
其他租户
  • 分类标签、部门标签：仅可选择网易 POPO 维护的标签，不可新增或编辑；仅在创建、编辑 Agent 时通过下拉选择。
  • 管理标签：仅显示展示标签，租户可自行新增、编辑。
03模型配置模块
模块迁移原 Fabric Models 迁移至 Studio 空间内。
账号接入租户可在 AIGW 申请应用维度模型账号，并通过 API 配置添加至 Models。
模型使用Models 中的模型可被 Agent 选择。
额度归属Agent 选用应用维度账号后，该 Agent 产生的全部模型额度从应用账号扣除，不扣个人额度。
04审批流相关
审核条件
  • 企业 Agent 首次上架必须审核。
  • 已上架后修改名称、头像、描述，分类、展示、部门标签或使用范围，触发重新审核；其他配置不触发。
  • 个人 Agent 上架不审核。
审核权限超管后台新增审核页；所有具备超管权限的用户均可审核。
审核通知支持配置审核通知。触发审核条件后，机器人向配置用户发送卡片，提醒进入审核。
生效规则仅“已上架”状态对消费侧展示；审核中、审核未通过均不展示。
