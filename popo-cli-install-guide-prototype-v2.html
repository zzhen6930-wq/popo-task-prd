方案要点

只推可用卡片

仅在默认安装成功后推送授权卡片，不推送无授权按钮的宣传型卡片，避免用户收到后无事可做。

按设备推送

几台设备安装成功就推几张卡片，卡片标注操作系统与 POPO 客户端设备号，用户可定位到具体电脑。

展示接入的 Agent

给哪些 Agent 装了 Skill 就展示哪些，chip 横排、流式换行，超过 5 个折叠为「等 N 个」。

一次授权即可用

卡片主按钮「立即授权」直接拉起 Open ID 登录，无需等到首次调用时再登录。
