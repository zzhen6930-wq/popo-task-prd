方案要点

一次性推送

不做管理后台与多轮触达，随客户端版本一次性完成检测与推送，用户不安装即不再打扰。

有 Agent：默认安装

客户端检测到已支持的 Agent 后静默完成 POPO-CLI 安装，无需用户任何交互。

安装后告知

机器人卡片说明新版客户端已自带 POPO-CLI，介绍打通的办公场景与首条指令用法。

无 Agent：自助安装

卡片介绍 POPO-CLI 与核心能力，半屏提供 Agent 自助安装与指定路径手动安装两条路径。
